# Core Problems & Deliverables

## The Problem
Build a Christianity-focused AI assistant that:
- Answers Christianity-related questions accurately
- Generates Christian content and themed images
- Stays aligned with Biblical context
- Avoids hallucinating scripture references
- Avoids producing offensive/heretical/toxic outputs
- Maintains conversational tone consistency

## Deliverables

1. **Working Demo** - Functional chat interface with all core features
2. **GitHub Repo** - Complete source code with proper structure
3. **Architecture Note** - Short document explaining technical decisions
4. **5-8 Minute Walkthrough** - Presentation/demo of the solution

## Expected Completion Time
~5 hours max using AI coding tools
