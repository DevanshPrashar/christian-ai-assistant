# Evaluation Criteria

What we will evaluate:

- **Prompt Engineering** - How well prompts are crafted to get accurate, safe, and contextually appropriate responses
- **Grounding Strategies** - Methods used to keep responses aligned with true scripture and Biblical context
- **Multimodal Workflows** - Integration of text and image generation in a cohesive pipeline
- **AI Safety Thinking** - Proactive measures to prevent harmful outputs
- **Hallucination Handling** - Detection and prevention of fabricated scripture references or facts
- **Architecture Decisions** - Design choices for scalability, reliability, and maintainability
- **Edge-case Handling** - Ability to gracefully handle adversarial, contradictory, or tricky inputs
- **Product Thinking** - How the solution addresses real user needs and delivers value
