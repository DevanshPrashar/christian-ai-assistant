# Core Requirements

## Chat Interface
- User-friendly interface for conversation
- Support for text-based interactions
- Clear response display with proper formatting

## Scripture-Aware Responses
- Answers must reflect accurate Biblical knowledge
- Contextual understanding of theological concepts
- Proper handling of denominational perspectives

## Bible Verse Grounding/Citations
- All scripture references must be verifiable
- Include accurate book, chapter, and verse citations
- Cross-reference against known Bible verse database
- Reject or flag unverified scripture claims

## Christian Image Generation Flow
- Generate Biblically accurate themed images
- Handle image prompt moderation
- Support for common Christian imagery (crosses, nature, biblical scenes)
- Policy compliance in generated images

## Conversation Memory
- Maintain context across multiple exchanges
- Remember user preferences and denominational leanings
- Track conversation history for coherent responses

## Basic Moderation/Safety Layer
- Filter offensive/heretical content
- Block toxic or extreme religious content
- Prevent the assistant from being weaponized
- Graceful refusal for policy-violating requests

## Denomination-Aware Handling
- Respect Catholic, Protestant, Orthodox, and other traditions
- Avoid favoring one denomination over others
- Be neutral in doctrinal disputes while staying Biblically accurate
- Allow users to specify denomination preference

## Handling Difficult Theological Questions Gracefully
- Acknowledge complexity when appropriate
- Present multiple perspectives without pushing one view
- Avoid definitive statements on debated theological issues
- Invite continued dialogue on sensitive topics
